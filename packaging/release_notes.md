The sprint 2 flight test: fly the ship around a wrap-around asteroid field and tune how it handles.

**Download:** `BitMiner-FlightTest-windows.zip` below. Unzip it anywhere (Desktop or Downloads is fine), open the `BitMiner` folder and double-click `BitMiner.exe`.

If Windows shows *"Windows protected your PC"*, click **More info**, then **Run anyway**. The game isn't signed with a publisher certificate yet, so Windows doesn't recognise it.

**Controls:** W main booster, S retro, A and D strafe, mouse to aim. Tab shows or hides the tuning panel, C toggles the CRT filter, R puts the ship back at the start, F11 is full screen, Esc quits.

**Tuning:** drag the sliders while you fly. Your settings save to `flight_tuning.json` next to `BitMiner.exe`. Send that file back when the ship feels right.

This build is made automatically from the latest commit on the sprint branch.
